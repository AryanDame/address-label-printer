# Address Label Printer

Print an address on any of the 21 labels of self-adhesive sheet 32091 (70 × 41 mm, 3 across and 7 down on A4), in exactly the right place.

**Open it here: https://aryandame.github.io/address-label-printer/**

Use Edge or Chrome on a computer. In the print window choose paper size A4, Scale 100% (not Fit to page), Margins Default, and switch Headers and footers off.

The page is one self-contained HTML file. Everything you type stays in your browser; it loads nothing from outside and sends nothing anywhere.
