# Address Label Printer

Print addresses on self-adhesive label sheet 32091 (70 × 41 mm, 3 across and 7 down on A4). Click the label you want on a picture of the sheet, type or pick an address, check the enlarged preview, and print it in exactly the right place. Every address you print is kept in an address list beside the sheet, newest first, so the next label for the same person takes two clicks. Search the list by name, street, town or country (accents are optional, so kovac finds Kovač), save an address without printing it, or delete one you no longer need. Long addresses shrink by themselves so every line stays on the label, and you can make the first line bold, centre the text, choose the font and the largest size, and put the last line in capitals. After printing, the label is marked as used and the next free one is chosen for you.

**Open it here: https://aryandame.github.io/address-label-printer/**

Use Edge or Chrome on a computer. In the print window choose paper size A4, Scale 100% (not Fit to page), Margins Default, and switch Headers and footers off.

The page is one self-contained HTML file. Your sheet, your address list and your text options are saved in your own browser on this computer; nothing is sent anywhere, and the list is not shared with anyone else. A sheet saved by the previous version carries over automatically.
